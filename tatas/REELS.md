# Tech 4 Tatas — Reels + voiceover lane (Phase 2)

Additive lane alongside the Phase 1 carousel pipeline. Generates spoken
scripts + hooks for Instagram Reels, gates them behind a review-first hook/tone
approval, then produces a voiceover + a CapCut-ready brief bundle per approved
item.

**This lane does NOT auto-post.** Reels need trending audio added in-app, so it
ends at a downloadable bundle (script + hooks + shot list + caption + voiceover
mp3), not a live post.

Full run steps land as Phase 2 completes.
